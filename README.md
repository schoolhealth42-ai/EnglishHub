# 🎧 English Hub — تطبيق تعلّم الإنجليزية (APK)

بودكاست + قنوات يوتيوب + راديو مباشر + محادثة وتدريب نطق + لوحة إعدادات كاملة.

## المزايا
**الاستماع**
- 12 بودكاست مختار (BBC 6 Minute English، VOA، All Ears English، Luke's English Podcast …) مصنّفة حسب المستوى.
- البحث في دليل Apple Podcasts وإضافة أي برنامج، أو إضافة رابط RSS مباشرة.
- مشغّل متقدّم: سرعة 0.5x–2x، تقديم/ترجيع، **تكرار A-B** لجملة صعبة، **وضع الظل (Shadowing)** يتوقف تلقائياً لتكرر بصوتك، مؤقت نوم، حفظ موضع الاستماع، تعليم الحلقات المسموعة، التشغيل التلقائي للتالية، والتشغيل في الخلفية مع إشعار تحكّم.
- راديو مباشر ناطق بالإنجليزية (BBC World Service، NPR، LBC …) مع بحث في آلاف الإذاعات.

**المشاهدة**
- 10 قنوات يوتيوب تعليمية (BBC Learning English، English with Lucy، Rachel's English …) مع أحدث الفيديوهات وتشغيل داخل التطبيق وترجمة إنجليزية تلقائية (CC).
- إضافة أي قناة برابطها أو @اسمها.

**المحادثة والتدريب**
- 13 حواراً لمواقف يومية (مطار، فندق، طبيب، مقابلة عمل …) مع ترجمة عربية و**لعب أدوار**: التطبيق ينطق شخصية وأنت تنطق الأخرى ويقيّم نطقك.
- محادثة حرّة: أسئلة تجيب عنها بصوتك.
- 60+ عبارة محادثة في 9 فئات مع تقييم النطق.
- تدريب النطق: يلوّن الكلمات الصحيحة بالأخضر والخاطئة بالأحمر.
- قاموس (تعريف، نطق، أمثلة، مرادفات + ترجمة عربية) وترجمة إنجليزي ⇄ عربي.
- بطاقات مراجعة بنظام التكرار المتباعد (Leitner) وكلمة اليوم ونصيحة اليوم.

**لوحة الإعدادات**
المظهر (داكن/فاتح/تلقائي، 7 ألوان، حجم الخط) • المستوى والهدف اليومي • لهجة النطق US/UK/AU وسرعته وطبقته • لغة التعرّف على الصوت • إعدادات التشغيل • تذكير يومي بإشعار • توفير البيانات • إدارة البودكاست/القنوات/الإذاعات • إحصائيات أسبوعية • نسخ احتياطي واستعادة • روابط مفيدة مختارة.

## طريقة بناء ملف APK من الجوال (بدون كمبيوتر) عبر GitHub
1. أنشئ حساباً على github.com ثم مستودعاً جديداً (New repository) — مثلاً `EnglishHub`.
2. فك ضغط الملف، ثم ارفع **كل محتويات** مجلد `EnglishHub` إلى المستودع (Add file ← Upload files).
   - ملف سير العمل داخل مجلد مخفي `.github/workflows/build.yml`؛ إذا لم يُرفع، أنشئه يدوياً: Add file ← Create new file، واكتب الاسم `.github/workflows/build.yml` والصق محتواه.
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (أو اضغط Build APK ← Run workflow). يستغرق ~5 دقائق.
4. عند الانتهاء افتح **Releases** في صفحة المستودع ونزّل `EnglishHub.apk` وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## أو عبر Android Studio
افتح المجلد ← Build ← Build APK(s). أو من الطرفية: `./gradlew assembleRelease`.

- الحد الأدنى: Android 8.0.
